===== Correction Note =====
Before disabling #Default_Network_Policy, a TCP/22 test to 1.1.1.1 was still shown as allowed by #Default_Network_Policy in Sophos logs.
This confirmed that the broad rule was still active at that time.
After disabling #Default_Network_Policy, the TCP/22 test was no longer successful from the client perspective.

===== Interpretation =====
The rulebase now follows a more specific allow-list approach for web traffic.
HTTP and HTTPS are handled by a dedicated logged rule.
The broad any-service LAN-to-WAN fallback rule is disabled.
The client can still resolve DNS and access HTTPS websites.
Non-web TCP/22 is no longer broadly successful from the client perspective.

===== Rollback Note =====
If required, #Default_Network_Policy can be re-enabled because it was disabled rather than deleted.
