# VPN Design Notes

## Purpose

This document collects VPN fundamentals for the Sophos Security Lab.

## VPN Types

| VPN Type | Typical Use |
|---|---|
| SSL VPN Remote Access | Remote user access into internal networks |
| IPsec Site-to-Site | Permanent tunnel between locations |
| IPsec Remote Access | Remote access using IPsec client configuration |

## Security Considerations

- user groups
- MFA where possible
- least-privilege access
- split tunnel vs. full tunnel
- logging and monitoring
- client certificate handling
- revocation and offboarding process

## Lab Scope

The initial lab focuses on VPN understanding and documentation.
A practical VPN test can be added later if the local network situation allows it safely.
